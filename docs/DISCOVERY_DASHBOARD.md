# Discovery dashboard

The company website presents the findings from one completed analysis report, followed by conditional valuations, business analysis, current developments, PDF/Excel downloads and the verification register.

Every visible finding has a verification label and source links. Financial observations are recalculated from that report's frozen history; comparisons cite all contributing periods, including the earlier denominator year for growth comparisons. Document claims require a matching archived passage and quote. Unresolvable claims are withheld. External update links remain labelled according to their verification limits.

Source citation is not independent verification. The dashboard does not grant a verified-discovery badge without an independent attestation. Valuations remain conditional estimates, and market-reference, valuation, report and news dates are shown separately.

Selecting another company clears the previous results. Generating research still starts a fresh investigation through the existing pipeline. Explicit report links reopen their exact saved snapshot. Interrupted polling resumes the same investigation rather than submitting a duplicate. Findings cannot fall back to another company or a previous report.

Validation: 220 automated tests pass, including eight dashboard evidence/identity tests. Browser checks cover all five populated companies, source links and verification labels, company switching, same-page report navigation, desktop layout and a 390px mobile layout. The existing polling recovery check also passes. This redesign does not change the Excel formulas, PDF generation or financial assumptions.

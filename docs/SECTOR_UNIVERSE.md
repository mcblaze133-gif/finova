## Shared pipeline

Each requested investigation reads the company evidence pack and performs a new update check. Targeted public-source retrieval now runs before the final sector review so the reviewer can use the originals that were actually obtained. Both drafting and review receive the historical reporting bases, periods and current date. Historical strategy, demerged operations and undated statements cannot establish current ownership or strategy merely because they match a keyword.

All company outputs use the same pipeline. Company-specific historical inputs, sources, assumptions, selected methods and segment data remain explicit. These are necessary financial inputs, not evidence of completely autonomous intake or method selection.

## Operating comparison

The shared comparison module selects a unique annual closing period on each company's reviewed forecast basis. All included amounts need source-file hashes and archived page links. A 15-month period is excluded from annual comparisons. Growth requires adjacent annual periods on the same basis. Missing values stay unavailable; zero debt remains a real zero.

Excel calculates revenue growth, EBITDA margin, CFO/parent profit, capex/sales and net debt/sales. The website and PDF read those saved formula results, including the original source references. Editable source cells recalculate the workbook. HUL's unresolved comparable capex is not filled with total-group or estimated spending.

These are reported operating benchmarks. ITC's tobacco/agri/paper mix, continuing versus total operations, acquisitions, geographic exposure, and different EBITDA definitions preclude automatic valuation ranking. Independent issuer authenticity, normalised earnings and category fit are not established by file hashes or a common period end.

## Valuation peer work still required

Peer-backed multiples need a matched-date verifiable price observation, the share count adjusted to that date, a complete enterprise-to-equity bridge, normalized attributable earnings/EBITDA, a common historical or forward period, and a sourced category/segment fit. The existing market references do not meet every one of those conditions. Direct archive requests timed out, but the official NSE browser interface successfully supplied Equity / Historical Data / Trade Data CSVs for all five companies, including 23 October 2026 EQ closes. Those original downloads and a source/hash register are kept in the user's private closing-price folder. This establishes the observation source; it does not finish the remaining share-count, corporate-action and earnings reviews or silently replace dated model inputs.

The operating comparison assigns no target multiple, premium, valuation weight or peer approval. Existing multiple stress cases retain their labels and zero reconciliation weights. A completed comparable-company valuation must additionally explain peer inclusion/exclusion, selected multiple range and its growth, margin, ROCE, leverage and quality adjustments.

## Additional safeguards

Malformed or citation-rejected empty operating sections receive at most one bounded repair request before the ordinary critic, while valid sibling sections are retained. A failed repair remains missing. The daily cap and provider limits still apply.

Reviewed ownership changes can be supplied as private source inputs in `data/scope-events.json`. A matching company, archived file hash and exact page quote are mandatory. An unreconciled present-tense claim about the affected entity is withheld, including when a model reviewer accepts it. These inputs require review and do not establish a live ownership register or automatic numerical adjustments.

Local cash-price CSV intake rejects SLB filenames, settlement/lending-contract headers and non-EQ series. It requires explicit matching trade dates, finite positive closes and consistent duplicate observations. NSE Quote-Equity exports without a symbol column require an exact instrument-bearing filename; a conflicting row symbol is rejected. Valid-format rows are candidates, not authenticity attestations or automatic market-price overrides. All twelve supplied SLB exports were rejected without changing valuations. The five separately downloaded EQ files pass the common-date intake check.
